# 방정식 예제와 원래 용어 병기 — 2026-09-10

## 반영 내용

- 최종 개요의 단순 분수 예제를 `(x+1)^2=9`로 교체했다. 구조 설명, 수식 도식, 페이지 예제, 정상·부분·실패 비교를 함께 바꿨다.
- 한국어 설명을 유지하며 주요 개념 뒤에 원래 용어와 코드 이름을 괄호로 병기했다. 별도 [용어 대응표](TERMINOLOGY_CROSSWALK.md)에도 방정식 구조 요소를 추가했다.
- 다섯 도식의 한국어 역할과 원래 명칭 사이에 줄바꿈을 넣었다. 전체 구조도는 세로 방향으로 배치하고, 겹치던 입력·출력 화살표 설명을 하나의 양방향 연결로 정리했다.

## 구현과 대조한 예제

[실행 코드](evidence/equation_examples.py)와 [실행 결과](evidence/equation-examples.json)는 현재 구현에 통제 입력을 넣어 얻었다.

| 확인 항목 | 결과 |
|---|---|
| 구조 | 등호 관계(Relation), 거듭제곱(Power), 괄호(Parenthesized), 숫자(Number) |
| 해석 상태 | 정상식 VALID, 미지원 명령을 넣은 식 PARTIAL, 등호 오른쪽이 없는 식 INVALID |
| 발화 규칙 결과 | 괄호 열고 x 더하기 1 괄호 닫고의 2 제곱은 9와 같다 |
| 점자 | 13칸, 시작 위치 0의 10칸과 시작 위치 10의 3칸 |
| 창 경계 | 등호의 두 점자칸이 두 창에 나뉨. 기호 단위 줄바꿈을 구현했다고 설명하지 않음 |
| 실행 경계 | 순수 변환·통제된 페이지 입력. 실제 사진 추론·Piper 청취·직렬 전송·모터 구동 없음 |

이 시스템이 방정식의 해를 계산하는 것으로 오해하지 않도록 명시했다. 10칸 전송 형식의 빈칸 채움은 형식 설명이며 실제 전송 증거가 아니다.

## 검증과 기록 구분

- Mermaid 11.12.0과 headless Edge로 다섯 도식을 실제 렌더링했다. [렌더링 기록](evidence/equation-render/render-results.json)과 PNG/SVG를 보존했다. 전체 구조·실행 흐름·수식 도식의 화면을 확인하고 화살표 설명 겹침을 교정했다.
- [최종 무결성 검사](evidence/equation-revision-validation.json)는 현재 문서와 렌더링 해시, 로컬 링크, 예제 결과, 기준 source 247개와 HEAD를 확인한다.
- [변경 전 사본](EQUATION_REVISION_BEFORE.md.snapshot)과 이전 분수 예제의 실행·검증 기록은 과거 산출물로 유지한다. 현재 개요의 방정식 예제에 대해서는 이번 실행 결과를 사용한다.
- 이전 191개 회귀 테스트의 결과를 이번 실행으로 재표기하지 않는다. 이번 변경은 문서·예제 조사 코드만 대상으로 하며 product source·firmware 변경은 없다.
