# 핵심 원리 선정표

2026-09-10. 입력: 완료된 용어 병기 작업과 [보강 계획](CORE_PRINCIPLES_EXPANSION_PLAN_20260910.md), PASS0–4 분석 및 현재 소스의 진입점. 이 선정표를 완료한 뒤 근거 카드와 예제를 조사한다. 이 시점에는 심화 본문을 작성하지 않는다.

| ID | 판정 | 다루는 사용자 문제 | 포함 근거와 경계 | 후속 확인 |
|---|---|---|---|---|
| K1 | 포함 | 수식 구조가 평문으로 뭉개지거나 음성·점자가 서로 다르게 해석됨 | LaTeX→AST와 두 출력 소비 경로 존재. 계산·OCR 정확성 보장과 구분 | 원문과 AST 관계, 해석 상태, 탐색이 AST와 맺는 실제 관계 |
| K2 | 포함 | 페이지 인식 결과를 어떤 순서·단위로 읽어야 할지 모호함 | VL→Page IR→문제 구성→읽기 항목 경로 존재 | 위치·순서·표·문제 membership의 보존/축약을 작은 페이지로 재현 |
| K3a | 포함 | 같은 펼친 면을 다시 촬영하거나 인식 흔들림을 새 페이지로 오판 | raw pair 관측·accepted reference·page-change gate 존재 | SAME early exit, 반복된 novel pair, 영상·숫자 추가 조건 |

| K3c | 포함 | 응답 유실 뒤 재전송으로 같은 작업이 두 번 반영됨 | V4 idempotency와 S0 command receipt 존재 | 같은 key+같은 payload 재사용, 같은 key+다른 내용 conflict |
| K3d | 포함 | 문제 구성 항목을 최상위에서도 다시 읽음 | flattening visited membership 존재 | 텍스트 내용 전역 dedupe가 아님을 예제로 확인 |
| K4 | 포함 | 저장·변환·출력 오류가 다음 단계의 성공으로 잘못 전달됨 | decode/readiness/hash/schema/revision/audio/FRAME 검사가 경계마다 존재 | 각 검사의 막는 실패·통과 의미·남은 한계를 분리 |
| K5 | 포함 | 재시작 위치 손실·연속 입력의 오래된 출력·완료 오해 | progress/receipt, generation/epoch, latest FRAME, 물리 feedback 부재 | 응답 유실과 재진입 예 및 각 번호의 책임 확인 |
| X1 | 보류 | 모델·알고리즘의 상대 성능을 알고 싶음 | 이 작업에 새 비교 실험 없음 | ‘최고·더 정확·더 빠름’ 같은 비교 우위 주장은 보류 |

선정 기준을 충족하는 K1–K5는 실제 호출 경로, 구체적 입출력, 사용자 실패와 연결된다. ‘채택 이유’는 기록된 설계 근거와 현재 코드에서 관찰되는 기능적 효과를 분리한다. 역사적 의사결정 기록이 없으면 개발자 의도를 만들어 쓰지 않는다. 비교 성능 증거가 없으면 핵심 구성상의 특징으로 설명하고 우수성을 단정하지 않는다.

완료: 후보 포함·보류·제외 결정. 다음 입력은 이 표와 기존 PASS2/3 근거이며, 다음 산출물은 근거 카드와 예제 결과다.
