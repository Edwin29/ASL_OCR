# Work Packets

프로젝트 작업 패킷을 저장소 루트와 분리해 보관한다. 구현 보고서, 검증 보고서, 운영 quickstart와 project
handoff는 기존 위치를 유지하고 패킷을 참조할 때 저장소 루트 기준 `docs/work-packets/<filename>`을
사용한다.

## 관리 규칙

- 새 프로젝트 루트 작업 패킷은 이 폴더에 생성한다.
- 패킷 파일명은 기존 `<SCOPE>_<MILESTONE>_WORK_PACKET.md` 규칙을 유지한다.
- 구현 결과는 패킷에 덮어쓰지 않고 기존 방식대로 별도 implementation/verification report에 기록한다.
- 완료된 패킷도 이 폴더에 유지해 결정과 범위의 이력을 보존한다.
